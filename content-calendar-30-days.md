## 📌 POSTING TIP — How to Maximise This Calendar

**Best posting times for Indian student audience (Instagram/LinkedIn):**
- **Weekdays:** 7:00–8:30 AM (before college) & 8:00–10:00 PM (post-study wind-down)
- **Weekends:** 10:00 AM–12:00 PM (relaxed scrolling window)
- **Best days:** Tuesday, Wednesday, Thursday for educational content; Sunday for emotional/aspirational posts

**Grid consistency rules:**
1. **Always** use the dark stone/black background + amber/gold accent formula — never post a bright white or random-coloured image.
2. **Alternate post types** in rows of 3 (e.g., hero shot → text card → lifestyle) so each Instagram row feels balanced.
3. Keep typography consistent — use one serif font for quotes and one sans-serif for info graphics across all 30 days.
4. Add the Wintrix logo or watermark subtly in the same corner (bottom-right) on every single post.
5. Use the same 5 core hashtags on every post (`#WintrixAcademy #DCET2027 #CrackDCET #GuidanceStrategySuccess #KarnatakaDiploma`) + 3–5 rotating niche hashtags.

**Reels/Video days (Days 11, 24):** Use Kling or Seedance with the same colour grading (dark + amber) and add a cinematic amber-tinted LUT for video consistency.
